# Brazilian E-Commerce Analytics Dashboard

Interactive Tableau dashboard analyzing regional sales performance 
using the Olist Brazilian E-Commerce dataset integrated with 
IBGE socioeconomic data.

## Dataset
- **Source:** Olist Brazilian E-Commerce Public Dataset
- **Size:** 1M+ rows
- **Enriched with:** IBGE socioeconomic data
- **Challenge:** Geographic normalization resolved using CASE statements
- **Performance:** Optimized via Live-to-Extract conversion

## Tools & Techniques
- Tableau Desktop
- Calculated Fields
- KPI Design
- Data Integration
- Extract Optimization

## Key Metrics Tracked
- Sales Revenue
- Average Order Value (AOV)
- Order Cancellation Rate
- On-Time Delivery Rate
- Customer Satisfaction Score
- Shipping Efficiency

## Dashboard Overview
- **2 interactive dashboards** covering sales and delivery performance
- **1 storyboard** for regional performance narrative
- **8 calculated KPIs** built from scratch
- **6 sheets** across all views
